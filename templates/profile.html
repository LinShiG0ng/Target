漏洞测试面板

通过修改 user_id 参数查看其他用户信息：

漏洞原因分析

问题代码：

user_id = request.args.get('user_id')
user = User.query.get(user_id)  # 未验证归属

接口接受外部传入的 user_id 参数，未验证该ID是否属于当前登录用户。

正确写法
# 方案1: 不接受外部参数
user = current_user

# 方案2: 验证归属关系
if user_id != current_user.id:
    return jsonify({'error': '无权访问'}), 403
